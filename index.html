01 // Architectural Intention LOC: 12.9716° N · 77.5946° E

Engineered With Intention.

A declaration of software resilience: building architectures that endure when reality departs from the happy path.

"We do not build for the happy path. We build for the crash mid-write, the concurrent tap, and the unannounced power interruption."

I am an undergraduate in Computer Science at Scaler School of Technology in Bengaluru, with my degree awarded by BITS Pilani. My methodology centers on identifying the edge cases in systems infrastructure and frontend viewports before they trigger production failure.

On the user interface frontier, I treat accessibility and layout integrity as non-negotiable structural requirements. A design system that collapses at 200% zoom or that relies on heavy script runtimes to establish spatial depth fails the engineering mandate. This entire portfolio proves that profound 3D perspective, responsive typography, and tactile micro-interactions can be forged using semantic HTML5 and advanced CSS3 alone.

01 // REAL-TIME CONCURRENCY

Kin

Shared Medication Schedule for Family Caregivers

A real-time care coordination web application built so two family members caring for the same relative never give the same dose twice. Every client watching a care circle updates over a WebSocket the instant a dose is recorded. When two requests land simultaneously, an atomic findOneAndUpdate ensures exactly one write wins and notifies the second caregiver.

⚡ Verified Concurrency: Swapping the atomic update for a standard read-then-write fails race tests; restoring it cleanly passes against 5 simultaneous mobile taps.

02 // AEROSPACE CAD PARSER

Balloon

Engineering Drawing to First Article Inspection Sheet

Parses toleranced dimensions out of complex engineering drawing PDFs and generates numbered First Article Inspection (AS9102) sheets. Reconstructs corrupted symbol glyphs where diameter symbols degrade into bare characters, stitching baseline text runs into coherent geometric callouts.

⚡ Air-Gapped Privacy: Standalone Go binary with vendored pdf.js. Zero network requests ever leave the host machine, guaranteeing proprietary aerospace and hardware IP remains completely confidential.

03 // STORAGE & FAULT INJECTION

Stow

Embedded Key-Value Store Tested by Simulated Power Loss

An embedded key-value storage engine in Go utilizing a Write-Ahead Log (WAL) and memory table. Because power cuts cannot be scheduled on demand with physical disks, Stow sits behind an instrumented VFS mock that forces simulated crashes at every single durability-relevant operation.

⚡ Exhaustive Failure Injection: 43 crash points tested against clean crashes and three torn-write variants (~170 recovery scenarios per suite run), enforcing atomic commit durability.
Go Write-Ahead Log Memtable VFS Mock Crash Simulation
