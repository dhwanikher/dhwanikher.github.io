Projects

01 · REAL-TIME APP

Kin

Shared medication schedule for family carers

A web app so two family members caring for the same person never give the same dose twice. Everyone watching sees updates instantly over a WebSocket. If two people tap at the same moment, one database write wins and the other person is told.

Tested: swapping the atomic update for a normal read-then-write fails the race test. Putting it back passes with 5 simultaneous taps.

02 · ENGINEERING TOOL

Balloon

Engineering drawing to inspection sheet

Reads dimensions and tolerances from engineering drawing PDFs and produces numbered First Article Inspection (AS9102) sheets. It also repairs damaged symbols, like diameter signs that turn into plain letters.

Private: it's a single Go program that runs offline. No data ever leaves your computer, so company drawings stay confidential.

03 · DATABASE ENGINE

Stow

Key-value store tested with simulated power loss

A small embedded database written in Go. It uses a write-ahead log so saved data survives a crash. Since you can't cut the power on demand, Stow runs on a fake file system that crashes at every important disk operation.

Tested: 43 crash points, each tried with a clean crash and three kinds of half-written data. That's about 170 recovery checks per run.
Go Write-ahead log Memtable Crash testing
