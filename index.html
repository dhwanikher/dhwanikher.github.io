01 // Architectural Intention LOC: 12.9716° N · 77.5946° E

Engineered
With Intention.

I approach digital engineering not as template composition, but as the deliberate construction of resilient mechanical architectures. Most software flourishes on the happy path where packets arrive linearly and electricity is continuous. I specialize in the parts of the architecture that fail when reality intervenes.

"Verified, not assumed: If a durability contract or concurrency invariant has not been subjected to simulated unannounced destruction and multi-threaded race conditions, it is merely a hypothesis."

On the user interface frontier, I treat layout integrity and accessibility as structural invariants. A design system that collapses when zoomed to 200% or that relies on heavy script runtimes to establish basic spatial depth fails the engineering mandate. This entire installation demonstrates that profound 3D perspective, responsive typography, and tactile micro-interactions can be forged using semantic HTML5 and advanced CSS3 alone.

01 // REAL-TIME CONCURRENCY

Kin

Shared Medication Schedule for Family Caregivers

A real-time synchronization system preventing critical double-dosing when two family members care for one patient. Every client viewing a care circle broadcasts over WebSockets. When two dosage updates land simultaneously, a single atomic findOneAndUpdate ensures exactly one write commits while immediately notifying the conflicting caregiver.

⚡ Verified Concurrency: Swapping the atomic update for a standard read-then-write immediately fails both race tests; restoring it cleanly passes against 5 simultaneous mobile taps.

02 // CAD ENGINE & AS9102

Balloon

Engineering Drawing to First Article Inspection Sheet

Parses toleranced dimensions out of complex engineering drawing PDFs and generates numbered First Article Inspection (AS9102) sheets. Reconstructs corrupted symbol glyphs where diameter symbols degrade into bare characters, stitching baseline text runs into coherent geometric callouts.

⚡ Air-Gapped Privacy: Standalone Go binary with vendored pdf.js. Zero network requests ever leave the host machine, guaranteeing proprietary aerospace and hardware IP remains completely confidential.

03 // STORAGE & FAULT INJECTION

Stow

Embedded Key-Value Store Tested by Simulated Power Loss

An embedded key-value storage engine in Go utilizing a Write-Ahead Log (WAL) and memory table. Since real physical disks cannot reliably arrange a power cut mid-write on demand, Stow sits behind an instrumented VFS mock that forces simulated crashes at every single durability-relevant operation.

⚡ Exhaustive Crash Replay: 43 crash points tested against clean crashes and three torn-write variants (~170 recovery scenarios per suite run), enforcing atomic commit durability.
Go Write-Ahead Log Memtable VFS Crash Mock
