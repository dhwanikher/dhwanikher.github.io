Kin

React · Node.js · MongoDB · WebSockets · Vitest

A shared medication schedule for families caring for one relative — built so two people in the same house never give the same dose twice. Every phone watching a care circle updates over a WebSocket the moment someone logs a dose; if two requests still land together, a single atomic findOneAndUpdate lets exactly one win and tells the other who got there first.

Accessibility is load-bearing, not a setting — the people using it are often in their seventies reading a phone at arm's length. At the largest text size a rigid two-column grid pushed the "Given" button off the edge; the layout now wraps instead.

Verified: replacing the atomic update with a naive read-then-write fails both concurrency tests — the race is real, and the fix is proven against it, not just theorized.

2

balloon

Go · pdf.js · AS9102 / GD&T

Turns an engineering drawing PDF into a numbered First Article Inspection sheet — the table of every toleranced dimension a machined part ships with, normally built by hand-drawing bubbles on a printout and retyping each value.

The drawing is the hard part. The same diameter symbol arrives as ⌀, Ø, or the bare letter j when a symbol font's character codes survive but its glyphs don't; a callout like ⌀12.50 ±0.05 usually splits across two separate PDF text runs that have to be stitched back together before they mean anything. One Go binary, pdf.js vendored — no network call ever leaves the machine with the drawing.

→ github.com/dhwanikher/balloon
3

stow

Go · WAL · memtable · simulated crash testing

An embedded key-value store, tested by being destroyed on purpose. A durable store's real failure — the power cutting out between two instructions — can't be arranged on demand on a real disk, so the filesystem sits behind an interface and the test suite substitutes one that simulates power loss at every durability-relevant operation a workload performs: 43 crash points, replayed with a clean crash and three torn-write variants — about 170 recovery scenarios per run.

Contract, stated precisely: when Put/Delete/Write returns nil with Sync enabled, the write survives a power cut. Nothing else is promised — and the tests hold the engine to exactly that, not more.
→ github.com/dhwanikher/stow
