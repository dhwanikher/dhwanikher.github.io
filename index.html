Featured Projects

01

Kin — Shared Medication Schedule

Real-Time Care Coordination for Families

A shared medication schedule designed so two caregivers caring for the same relative never administer the same dose twice. Every client watching a care circle updates over a WebSocket the instant a dose is recorded. If two simultaneous requests land together, a single atomic findOneAndUpdate guarantees exactly one succeeds and immediately alerts the second caregiver.

⚡ Verified Concurrency: Swapping the atomic update for a naive read-then-write immediately fails both concurrency race tests (two-person race and five simultaneous taps); restoring it cleanly passes both.
React Node.js MongoDB WebSockets Vitest Accessibility (a11y)

02

balloon — Drawing to Inspection Sheet

Automated First Article Inspection (AS9102 / GD&T)

Parses toleranced dimensions out of complex engineering drawing PDFs and generates numbered First Article Inspection (FAI) sheets — eliminating tedious manual bubble-drawing on paper printouts. Built to handle real-world text corruption where diameter symbols export as ⌀, Ø, or random glyphs.

⚡ Zero-Network Guarantee: Single standalone Go binary with pdf.js vendored. Runs 100% locally with zero external network requests, preserving proprietary engineering IP.
Go pdf.js AS9102 GD&T Regex Parser

03

stow — Embedded Key-Value Store

Tested by Simulated Power Loss Crash Injection

An embedded key-value storage engine in Go with Write-Ahead Logging (WAL) and an in-memory memtable. Because power loss cannot be scheduled on demand with physical disks, the filesystem sits behind an interface that simulates power failure at every single durability-relevant operation.

⚡ Exhaustive Failure Injection: 43 crash points, each replayed with a clean crash and three torn-write variants (~170 recovery scenarios per test run) verifying atomic durability contracts.
Go Write-Ahead Log Memtable VFS Crash Simulation
